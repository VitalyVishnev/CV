# Vitaliy Vishnev · CV

Сайт для GitHub Pages и PDF на русском и английском.

## Редактирование текста

- `content/ru.md` — русская версия.
- `content/en.md` — английская версия.

Это обычные Markdown-документы. Можно редактировать прямо на GitHub кнопкой Edit или в любом текстовом редакторе. Сайт и PDF используют один и тот же текст. Переводы редактируются отдельно.

```md
# Имя Фамилия

**Специализация**

Город · доступность

Короткое описание опыта.

## Опыт

### Название студии

**Должность · даты**

- Сделал инструмент для команды.
- Создал ландшафт.

## Проекты

### [Название проекта](https://example.com)

Описание проекта.
```

`#` обозначает имя, `##` раздел, `###` место работы или проект. Абзацы разделяются пустой строкой, пункты списка начинаются с `-`. Кавычки и запятые можно писать как обычно. Разделы можно переименовывать, добавлять и переставлять.

Первые три абзаца после имени — специализация, местоположение и доступность, описание опыта. Все ссылки и контакты находятся в этих же файлах.

После push в `main` GitHub Actions обновляет сайт и оба PDF автоматически.

## Локальный просмотр

Нужен Node.js 22 или новее.

```sh
npm ci
npx playwright install chromium
npm run build
npm run pdf
npm run preview
```

Предпросмотр: http://127.0.0.1:4173. Русская версия: `/ru.html`, английская: `/en.html`. PDF находятся в `dist/`.

Для PDF можно использовать установленный Chrome: задайте переменную окружения `CHROME_PATH` с полным путём к браузеру вместо установки Chromium.

Оформление сайта и печатной версии находится в `src/style.css`. Workflow публикации: `.github/workflows/pages.yml`.
