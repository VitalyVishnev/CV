# Vitaliy Vishnev · CV

Персональное резюме на русском и английском. Статический сайт для GitHub Pages и PDF на обоих языках в стиле Swiss / Editorial Minimalism.

## Как менять текст

Откройте `content/cv.json`. Общие контакты находятся в начале файла, русские тексты в `ru`, английские в `en`. Изменения применяются к сайту и PDF при следующей сборке. Переводы редактируются отдельно.

Не меняйте названия ключей. Сохраняйте JSON-синтаксис: двойные кавычки внутри строк экранируются, перенос строки записывается как `\n`.

## Локальная сборка

Нужен Node.js 22 или новее.

```sh
npm ci
npx playwright install chromium
npm run build
npm run pdf
npm run preview
```

Предпросмотр: http://127.0.0.1:4173. Главная страница на английском, `ru.html` на русском. PDF: `dist/vitaliy-vishnev-ru.pdf` и `dist/vitaliy-vishnev-en.pdf`.

Можно использовать установленный Chrome вместо скачивания Chromium: перед `npm run pdf` задайте переменную окружения `CHROME_PATH` с полным путём к исполняемому файлу браузера.

## GitHub Pages

В репозитории GitHub выберите **Settings → Pages → Source → GitHub Actions**. Workflow `.github/workflows/pages.yml` собирает сайт и PDF при push в `main`, затем публикует каталог `dist`. Относительные ссылки работают и в репозитории `/CV/`, и на собственном домене.

Удалённый репозиторий пока не подключён. Публикация начнётся после настройки remote и отправки файлов на GitHub.

## Структура

- `content/cv.json` — все тексты и контакты.
- `src/style.css` — оформление сайта и печатной версии.
- `scripts/build.mjs` — сборка HTML без клиентского JavaScript.
- `scripts/pdf.mjs` — PDF из того же HTML с печатными стилями.
- `scripts/serve.mjs` — локальный сервер предпросмотра.

Сгенерированный каталог `dist` и временные проверки не хранятся в Git. После изменения текста выполните обе команды сборки, чтобы обновить PDF.
